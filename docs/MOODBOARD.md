# Moodboard — Whatever · AI 附近去处决策工具

> 产品气质一句话：**轻决策工具，不是地图，不是攻略，是帮你拍板的 AI 朋友。**

---

## 一、气质定位

```
iOS 原生轻工具风
        ×
城市探索感（不是旅游感）
        ×
温和游戏化（不是抽卡娱乐感）
```

| 维度 | 参照 | 避开 |
|------|------|------|
| 工具感 | Apple Maps 的克制 | 大众点评的信息堆砌 |
| 探索感 | Foursquare City Guide 的轻盈 | 穷游/马蜂窝的攻略感 |
| 随机感 | 命运签的小仪式 | 老虎机/抽卡的娱乐感 |
| 文案感 | 朋友的直接推荐 | 小红书的种草腔调 |

## 二、色彩系统

### 主调

```
主色  ████████  #14B8A6   Teal-500     → 探索、出发、可信
强调  ████████  #F59E0B   Amber-400    → 决定、高亮、命运感
背景  ████████  #FFFFFF   White        → 主背景，高留白
底板  ████████  #ECECF0   Cool Gray    → 卡片衬底、分区背景
文字  ████████  #717182   Muted Gray   → 次要信息、辅助文案
```

### 使用原则

- **主色（Teal）**：CTA 按钮、选中态、进度条、AI 摘要条背景
- **强调色（Amber）**：抓阄完成高亮、结果页标题、风险标签
- **大面积留白**：背景保持白色或浅灰，不做深色底
- **禁止使用**：大红、亮紫、荧光绿 — 会变成娱乐产品调性

### 颜色组合示例

```
正常状态        选中状态        结果高亮
───────────     ───────────     ───────────
白底 + 灰边     Teal边 + Teal底  Amber文 + 白底
```

## 三、字体层级

```
H1  · 24px · Medium 500   今天想去哪？
H2  · 20px · Medium 500   新泾公园
H3  · 18px · Medium 500   人格试玩
Body· 16px · Regular 400  现在去比较轻松，适合一个人待一会
Sm  · 14px · Regular 400  公园 · 骑车12分钟 · ¥0
Xs  · 12px · Regular 400  傍晚人会变多
```

**原则：地点名要大，AI 判断语要短，辅助信息要小。三级之内，不做四级。**

### 5. 轻量抓阄动效

```
阶段一（1.2s 内完成）

  候选卡片         →   5个代号光点快速轮转   →   落定高亮
  ┌──┐ ┌──┐           ● ● ● ● ●                  ●
  │1 │ │2 │    →     快速切换高亮          →   新泾公园
  └──┘ └──┘           不停跳动                  震动反馈
  ┌──┐ ┌──┐
  │3 │ │4 │
  └──┘ └──┘
  ┌──┐
  │5 │
  └──┘

节奏感：轻仪式，不赌场
时长：1.2s ± 0.2s（不能太长）
反馈：最终落定 + 轻微震动（navigator.vibrate(80)）
文案：「命运抽签中……」→ 消失 → 「今天去这里」出现
```

**视觉关键词：** 轻、快、有落点感，不像赌博机器

### 6. 城市生活感氛围参考

```
光线感   →  高亮度底色，不做暗色主题（首版）
纹理感   →  无纹理，用留白和层级营造空气感
图标感   →  Lucide 图标（细线条），不用填充色图标
间距感   →  模块间 gap-8，卡片内 p-5，信息内 gap-2
动效感   →  全用 ease-out，150-300ms，不超过500ms
```

## 六、文案风格板

### 推荐语气（拍板型）

```
✓  今天去这里
✓  已替你排除不合适选项
✓  这个更适合你现在
✓  换一个也行
✓  在附近帮你找地方…
✓  让 AI 先替你筛一轮…
```

### 禁止语气（劝导型/攻略型）

```
✗  建议你先去这里再去那里
✗  这边很适合拍照打卡喝咖啡散步
✗  为你精心规划了半天路线
✗  打卡必去！！
✗  宝藏地点推荐
```

## 七、对标参照 & 避开清单

### 对标

| 产品 | 参考点 | 不参考点 |
|------|--------|----------|
| iOS Maps | 留白、字体层级、无装饰 | 3D地图、路线复杂度 |
| Fantastical | 卡片式、干净CTA | 日历密度感 |
| Coin Flip (小工具) | 仪式感动效 | 无 |
| Arc Browser | 探索感、颜色点缀 | 复杂手势 |

### 坚决避开

```
❌  大众点评风  → 信息密度高、打星、评论流
❌  小红书风    → 粉色、图文种草、打卡感
❌  高德/百度   → 深蓝、路网、密集POI
❌  抖音        → 全屏竖版、强娱乐感
❌  王者荣耀    → 金色描边、炫光、重动效
```

## 九、一句话设计原则

> **每一个设计决策，问自己一个问题：这会让用户更快拍板，还是让他又多想了一下？**

如果是后者，删掉。
