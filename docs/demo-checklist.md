# Demo Checklist (Day5)

> 目标：确保演示可重复、可验收、可对外讲。

## A. 演示前检查

- [ ] 后端服务已启动（8000）
- [ ] 前端服务已启动（5173）
- [ ] 前端 API Base URL 正确（`/api/v1` 代理到 8000）
- [ ] mock 数据可用（候选>=5）
- [ ] session 无脏数据影响（必要时清 localStorage）
- [ ] 历史页初始状态已确认（空/有数据都可解释）

## B. 主链路检查

- [ ] 首页输入需求成功发起 `recommend/init`
- [ ] 候选页成功拉取 Top5（`recommend/candidates`）
- [ ] 点击抓阄成功得到 1 个地点（`recommend/pick`）
- [ ] 结果页展示地点信息（名称/类型/ETA/预算/理由）
- [ ] 人格试玩可切换并返回内容（`persona/review`）
- [ ] 点击导航有明确反馈（成功或失败提示）
- [ ] 提交反馈成功（`feedback/submit`）
- [ ] 历史页出现本次记录（`history/list`）

## C. 异常态检查

- [ ] 候选为空可兜底（`empty_candidates`）
- [ ] 人格试玩失败可降级（`persona_timeout`）
- [ ] 网络失败有提示（offline）
- [ ] 导航失败有提示（前端模拟失败）
