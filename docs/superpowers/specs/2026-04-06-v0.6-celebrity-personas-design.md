## 目标

在结果页「人格试玩」区顶部增加付费名人视角行，首发接入乔布斯（Steve Jobs）。名人使用 `.skill` 格式的角色文件作为 LLM system prompt 生成 4 个场景切片评价。当前阶段只做 UI 锁定标记，无实际支付流程。

---

## 功能范围

**本次包含：**
- 结果页人格区重组（名人行置顶 + 免费 8 个人格不变）
- Jobs `.skill` 文件存入项目，后端加载为 system prompt
- `/persona/review` 接口扩展支持 celebrity 类型请求
- 前端点击锁定名人 → `ProGateSheet` 底部弹窗（纯 UI，无支付）
- 订阅状态存 localStorage（`pro_unlocked: boolean`，暂时手动设为 true 可解锁测试）

**不包含：**
- 实际支付接入
- 候选页改动
- 过渡动画优化
- 多名人扩展（框架搭好，仅上 Jobs）

## 后端架构

### Celebrity Skill 存储

```
backend/app/skills/
  jobs.skill          ← Steve Jobs skill 内容（从 GitHub 拉取）
  __init__.py
  loader.py           ← load_skill(name: str) → str
```

### `/persona/review` 接口扩展

新增请求参数 `celebrity: str | None`（可选）：

```json
POST /api/v1/persona/review
{
  "session_id": "...",
  "pick_id": "...",
  "persona": "乔布斯",
  "celebrity": "jobs"   ← 新增，非空时走 skill 路径
}
```

**处理逻辑：**
- `celebrity` 为空 → 现有 template/LLM 路径，不变
- `celebrity` 非空 → `load_skill(celebrity)` 作为 system prompt → LLM 生成 4 个场景切片 + summary
- LLM prompt 格式与现有切片格式一致（JSON，4 scenes: to_door/enter/during/leave）
- 失败 fallback：返回 `summary="这里值得一来"` + 空 slices

### LLM 调用（celebrity 路径）

```python
system_prompt = load_skill("jobs")  # jobs.skill 全文
user_prompt = f"""
你正在以自己的视角评价一个地点，供用户决策是否前往。

地点：{place_name}（{place_type}）
距离：约{eta_min}分钟
预算：{budget_text}

请输出 JSON（不要包含其他内容）：
{{
  "summary": "...",   // ≤20字，你的核心判断
  "slices": [
    {{"scene": "to_door", "tag": "...", "text": "...", "emotion": "..."}},
    {{"scene": "enter",   "tag": "...", "text": "...", "emotion": "..."}},
    {{"scene": "during",  "tag": "...", "text": "...", "emotion": "..."}},
    {{"scene": "leave",   "tag": "...", "text": "...", "emotion": "..."}}
  ]
}}
"""
```

## 数据流

```
用户点击「乔布斯」
  → isPro() 检查
    → false → ProGateSheet 弹出
    → true  → api.personaReview(sessionId, pickId, '乔布斯', 'jobs')
                → POST /persona/review { celebrity: 'jobs' }
                  → load_skill('jobs') → system prompt
                  → LLM 生成切片 JSON
                  → 返回 { summary, slices, review, ... }
              → setReviewCache('乔布斯', data)
              → PersonaSliceView 渲染切片
```
